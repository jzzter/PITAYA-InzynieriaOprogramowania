# PITAYA - system rezerwacji imprez turystycznych

**Zespół:** Jonasz Bals, Maksymilian Bruździak

Dział Informatyki Biura Turystycznego “PITAYA” posiada szeroki wachlarz ofert imprez
turystycznych przystosowanych do różnych potencjalnych uczestników. Oferty są
systematycznie uzupełniane, edytowane, ewentualnie usuwane. Zainteresowanie imprezami
turystycznymi jest wielkie, dlatego konieczne jest monitorowanie rezerwacji. Program powinien
zawierać system rezerwacji, przeglądania ofert, zarządzanie rezerwacjami (w tym: anulowanie,
dokonanie płatności) oraz edycję oferty. System powinien wspomagać rejestrację uczestników (klienci w formie osoby pojedyńczej bądź grupy osób).
System obsługują wyznaczeni konsultanci, którzy pełnią rolę pracowników biura podróży, oraz
administrator, który monitoruje system w celu znalezienia potencjalnych niedociągnięć i
pomyłek.

#

**Wymagania funkcjonalne systemu - System powinien:**
- pozwalać klientom na przeglądanie dostępnych ofert imprez turystycznych
- pozwalać zalogowanym klientom na rezerwowanie ofert i przeglądanie swoich rezerwacji (wraz z historią poprzednich)
- pozwalać na proste i funkcjonalne zarządzanie ofertami przez pracowników

**Wymagania niefunkcjonalne systemu - System powinien:**
- dbać o prywatność i ochronę danych osobowych, zgodnie z regulacjami prawnymi
- być zdolny do dostosowywania się do rosnącej liczby użytkowników i danych
